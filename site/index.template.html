从零到一：创建一个 TypeScript 7 项目

使用原生 TypeScript 7 CLI 完成类型检查和包构建，同时通过 TypeScript 6 兼容 API 保留 webpack 与 ESLint 工具链。

技术概览

一套配置，两条构建路径

tsconfig.json 是统一配置来源。包构建和 webpack 打包各自生成独立产物。

01

准备环境

使用 Node.js 22 安装开发依赖。

npm install
02

直接编译

TypeScript 7 生成 ESM、声明文件和对应映射。

npm run build:ts
03

webpack 打包

ts-loader 使用 TypeScript 6 API 生成独立 bundle。

npm run build:webpack
04

完整验证

依次检查格式、代码质量、类型和两条构建路径。

npm run check

验证流程

从安装到运行

迁移期架构

TypeScript 7 CLI 与 TypeScript 6 兼容层

主编译器

TypeScript 7

@typescript/native 提供 tsc。他负责类型检查、监听和直接包构建。

  • 输出 NodeNext ESM
  • 生成声明与源码映射
  • 保持严格项目配置
兼容工具链

TypeScript 6

@typescript/typescript6 提供临时编译器 API。webpack、ts-loader 和 typescript-eslint 使用该 API。

  • 保留 webpack 构建路径
  • 支持 ESLint TypeScript 分析
  • 避免 CLI 命令名称冲突
